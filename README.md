# Portfólio — Jean Carlos Amorim de Mello

Este é um portfólio estático em HTML e CSS, preparado para publicação no GitHub Pages.

## O que contém

- Apresentação profissional
- Projetos e estudos de caso
- Experiência profissional
- Competências demonstradas
- Contato por e-mail e LinkedIn

## Como visualizar no computador

1. Extraia o arquivo ZIP.
2. Abra a pasta `jean_portfolio_starter`.
3. Dê dois cliques em `index.html`.
4. O site será aberto no navegador. Não é necessário instalar programas.

## Como publicar com GitHub Pages

1. Crie um repositório público chamado `portfolio-jean-amorim` na sua conta do GitHub.
2. Envie o arquivo `index.html` para a raiz do repositório (pasta principal).
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)` e salve.
6. Aguarde a publicação e abra o endereço indicado na própria tela de Pages.

O GitHub Pages é hospedagem estática. Este portfólio não contém backend, login, formulário de envio ou banco de dados.

## Privacidade e precisão

- O código original do sistema de fiados NÃO está incluído.
- Não coloque aqui o arquivo `.env`, chaves do Supabase, senhas ou outros segredos.
- Não publique dados reais de clientes, fornecedores, colegas ou comprovantes.
- A planilha financeira original não deve ser publicada: use somente a descrição do estudo de caso, sem dados internos.
- O projeto web é descrito como protótipo assistido por IA, não como software desenvolvido manualmente pelo autor nem como sistema adotado pela empresa.
- O estudo de caso do comércio foi anonimizado. Peça autorização antes de acrescentar nome, marca, logotipo, capturas de tela ou informações internas da empresa.

## Personalização futura

Edite `index.html` com um editor de texto simples (por exemplo, Bloco de Notas ou Visual Studio Code). Procure pelo texto que deseja alterar e substitua com cuidado. Não remova as aspas dos atributos HTML nem as tags de abertura/fechamento.
