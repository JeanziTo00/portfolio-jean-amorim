## O que você encontrará

- Apresentação profissional e objetivos de carreira.
- Experiência com sistemas ERP/PDV e apoio a usuários.
- Projetos e estudos de caso com imagens das interfaces.
- Competências desenvolvidas na prática.
- Formas de contato profissional.

## Projetos apresentados

### 1. Sistema web de controle de fiados

Protótipo funcional criado com o Bolt.new para organizar clientes, compras, pagamentos, comprovantes, extratos e relatórios.

Minha participação envolveu identificar a necessidade, levantar e especificar requisitos, testar manualmente as funcionalidades, criar cenários de uso, identificar divergências e solicitar ajustes. O código foi gerado com auxílio de inteligência artificial. O protótipo foi testado na empresa, mas não chegou a ser adotado na rotina.

### 2. Automação de atalhos e calculadora para PDV

Conjunto de macros e uma calculadora de troco desenvolvidos com AutoHotkey e assistência de IA para reduzir etapas repetitivas durante o atendimento no caixa.

Minha participação envolveu identificar os gargalos, definir o comportamento esperado, orientar a criação das ferramentas e testar os resultados. A calculadora continua sendo utilizada na rotina de atendimento.

### 3. Controle de despesas

Estudo de caso de uma planilha de acompanhamento de despesas, vencimentos e pagamentos, construída com auxílio de IA.

Minha participação envolveu documentar requisitos, testar a primeira versão, identificar situações não previstas e registrar melhorias para refinamento. Não desenvolvi manualmente as fórmulas da planilha.

## Transparência sobre os projetos

Nos projetos de software e automação apresentados, a implementação do código foi realizada com auxílio de ferramentas de inteligência artificial. Minha contribuição esteve na identificação de necessidades, levantamento de requisitos, especificação funcional, testes manuais, validação e refinamento.

Esses projetos **não são apresentados como experiência de programação independente**. Meu objetivo é demonstrar experiência prática em compreender problemas operacionais e avaliar soluções tecnológicas.

## Sobre este repositório

O site é uma página estática publicada pelo GitHub Pages. O arquivo principal é `index.html`; as capturas utilizadas na galeria estão incorporadas à página.

As imagens de demonstração utilizam dados fictícios. Não incluo neste repositório o código-fonte das aplicações de terceiros, arquivos de configuração privados, credenciais, senhas, chaves ou dados internos da empresa.
